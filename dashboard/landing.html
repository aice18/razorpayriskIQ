Platform FAQ

Frequently Asked Questions

Technical specifications regarding latency budgets, carrier NAT handling, and regulatory compliance.

How is sub-10ms latency maintained during graph traversals? [-]
RiskIQ decouples the checkout hot-path from deep agentic investigation. Degree centrality and sliding-window velocities are extracted via O(1) Redis sorted sets in under 1ms. The full 2-hop NetworkX subgraph traversal and LLM agent reasoning run asynchronously in worker tiers.
How does the engine avoid false positives on shared carrier IPs? [+]
RiskIQ incorporates inverse logarithmic hub dampening with formula W = 1 / log2(2 + k). When an IP node connects to large volumes of unique devices (e.g. Jio or Airtel public NAT gateways), the edge weight diminishes asymptotically, preventing false ring alerts.
How are model attributions verified for regulatory audits? [+]
Every transaction scoring response includes normalized TreeSHAP feature attributions detailing the exact statistical weight of velocity, degree, category deviation, and device anomaly parameters.
